# agathachristie.no

Website for the Agatha Christie quiz team, served by GitHub Pages.

For now it shows live status for the team's Valheim server, *Agatha's Valkyrier*:
online/offline, how many are playing, in-game day and bosses defeated. The status
comes from a public gist that the server's watcher (in the private homelab repo)
updates when something changes; the page fetches it in the browser. No home IP,
address or password is published.
